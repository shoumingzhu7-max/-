# API 余额查询（带消耗总结）

这是一个运行在 Windows 上的**单文件小工具**，用来查询多个 AI 平台（Kimi / DeepSeek）的 API 余额，并自动统计你每天的消耗。它把所有数据画成饼图和柱状图，让你一眼看清"今天花了多少、这个月花在哪、全年趋势怎么样"。

它不需要安装、不需要联网注册、不需要写代码。下载下来双击就能用。

---

## 一、这个工具能帮你做什么

如果你平时在用 Kimi、DeepSeek 这类平台的 API，最烦的就是：余额到底还有多少？昨天花了多少？这个月烧了多少钱？这个工具就是解决这个问题的。

它一次能管理**两个 API key**（比如一个给 Kimi，一个给 DeepSeek），并自动帮你算出：

| 统计维度 | 说明 |
| --- | --- |
| 今日消耗 | 今天一共花了多少钱 |
| 本周消耗 | 从本周一到现在的花费 |
| 本月消耗 | 从本月 1 号到现在的花费 |
| 年度消耗 | 今年累计花了多少钱 |

除了数字，它还提供**四个饼图**（今日 / 本周 / 本月 / 年度）和一个**按月的柱状图**，方便你直观对比。

---

## 二、开始使用（三步上手）

### 第 1 步：下载并双击

把 `API查询.vbs` 下载到电脑任意位置，双击运行。

如果 Windows 弹出"是否允许此应用对你的设备进行更改"，点 **"是"**。这是 Windows 对脚本的常规提醒，不是病毒。

打开后是一个窗口，标题是 **"API 余额查询（带消耗总结）"**。

### 第 2 步：填两个 API key

窗口上方有两个输入框：

- `Key 1` —— 填你的第一个 API key
- `Key 2` —— 填你的第二个 API key

> **不用手动选平台。** 工具会根据 key 的特征自动判断是 Kimi 还是 DeepSeek：
>
> - Kimi 的 key 通常以 `sk-` 开头，查询走 Moonshot 接口
> - DeepSeek 的 key 通常以 `sk-` 开头，查询走 DeepSeek 官方接口
>
> 如果 key 填的是 Kimi，右侧余额标签会显示 **Kimi**；如果是 DeepSeek，会显示 **DeepSeek**。

填好后，点一次 **"刷新余额"**。

### 第 3 步：看结果

刷新后你会看到：

- Key 1 和 Key 2 各自的**当前余额**
- 今日 / 本周 / 本月消耗的**汇总金额**
- 四个饼图（年度消耗、本月消耗、本周消耗、今日消耗）

---

## 三、图表怎么用（重点）

### 饼图（今日 / 本周 / 本月 / 年度）

- 每个饼图代表一个时间段的消耗占比。
- 把鼠标**悬浮在饼图某一块**上，会弹出一个小提示，显示该部分对应的平台（Kimi 或 DeepSeek）和金额占比。

### 柱状图（按月查看全年）

**默认显示全年每个月的消耗**：

- 横轴 = 月份（1 月、2 月、3 月……）
- 纵轴 = 消耗金额（单位：元，人民币）
- 鼠标**悬浮在某一列上方**，会显示该月花了多少钱。
- 右上角可以切换 **全部 / Key 1 / Key 2**，只看某个 key 的消耗。

### 点击某个月 → 查看那一天

这是最常用的功能：

1. **点击柱状图中的某个月**，图表会切换成**这一月逐日**的视图。
2. 横轴变成"1 号、2 号、3 号……"，纵轴还是金额。
3. 鼠标悬浮在某一列，会显示"这一天一共花了多少钱"。
4. 查看完，点左上角的 **"返回"** 按钮，就回到按月视图。

> 注意：当某天消耗为 0 时，这一天不会显示柱子（避免一堆 0 高度的柱子挤在一起，看起来更干净）。

## 四、高级设置

### 自动刷新

默认是**手动刷新**（你点"刷新余额"才会更新）。

如果你想让它自己定时更新：

1. 点 **"自动刷新"** 开关，把它打开。
2. 开关右侧有一个**齿轮图标**，点它会在下方展开刷新间隔选项。
3. 你可以选 **30 秒 / 45 秒 / 60 秒**。
4. 选好后，工具会每隔这么长时间自动刷新一次余额。

### 查看详情表格

在消耗汇总下面有个 **"查看详情"** 链接。点它会展开一个表格，列出每个 key 更细的消耗记录。再点一次可收起。

## 五、配套自启动脚本（可选）

如果你希望"一打开某个 AI 工具，就自动弹出余额窗口"，可以用配套的 `自启动脚本.vbs`。

### 怎么用

1. 把 `自启动脚本.vbs` 和 `API查询.vbs` 放在**同一个文件夹**里。
2. 双击 `自启动脚本.vbs` 运行一次。
3. 它会在后台常驻，检测下面这些程序是否被启动：
   - Codex
   - Cursor
   - Claude
   - Gemini
   - Continue
   - OpenClaw
4. 只要其中一个启动了，它就自动帮你打开余额窗口。

### 怎么改监听名单

用记事本打开 `自启动脚本.vbs`，找到顶部这一行：

```vb
TARGET_APPS = Array("codex", "cursor", "claude", "gemini", "continue", "openclaw")
```

改成你想要的程序名（程序名就是任务管理器里显示的进程名，不带 `.exe`），保存即可。

### 几个小规则

- 触发后 **30 秒内不会重复弹窗**，防止反复打断你。
- 如果窗口已经开着，它不会重复开第二个。
- 虽然监听多个程序，但只有**一个**余额窗口，不会开一堆。

## 六、常见问题（排错）

**Q1：双击后 Windows 提示脚本错误怎么办？**

如果弹的是"对象不支持 log10 属性或方法"之类的错，是因为这个工具用的是旧版 Windows 脚本引擎。请确认你使用的是**最新脚本文件**（`API查询.vbs`），旧版本可能没有修复。如果仍报错，把报错截图发到 Issues，我会修复。

**Q2：填了 key 但查不到余额？**

先确认：

- key 是否完整、复制时有没有多空格
- key 对应的平台是否还能正常使用（有些 key 会过期）
- 网络是否正常（工具需要联网访问 Moonshot / DeepSeek 接口）

如果还是不行，看窗口里每个 key 旁边的状态文字，它会提示"查询中…"或错误原因。

**Q3：为什么某个月没显示柱子？**

因为那一天或那一个月消耗为 **0**，工具为了图表干净，不画 0 高度的柱子。这是正常行为。

**Q4：我的 API key 会被上传吗？**

**不会。** 所有数据都在本机计算，key 只保存在你电脑的当前用户注册表里，统计记录保存在本机 `%APPDATA%` 内存目录，不上传任何服务器。

**Q5：我想监听别的程序，怎么加？**

打开 `自启动脚本.vbs`，在 `TARGET_APPS` 数组里加一个名字即可，例如 `"claude"`。注意名字必须是任务管理器里的**进程名**（不带 `.exe`）。

## 七、隐私说明

- 本工具**不收集、不上传**任何使用数据，所有统计只在本机完成。
- 你的 API key 由你自己填写，保存在本机注册表 `HKCU\Software\APIKeyBalance\`。
- 消耗记录保存在本机 `%APPDATA%\AIBalanceCheck`，删除该文件夹即可清空历史。
- 工具只在你手动刷新或开启自动刷新时访问 Moonshot / DeepSeek 的余额接口。

## 技术实现（给好奇的人）

- 用 Windows 自带的 **VBScript + HTA**（旧版 MSHTML）编写，无需安装任何运行时。
- 图表是用 **HTML5 Canvas** 手绘的，不依赖第三方图表库。
- 网络请求走 **WinHttp**，兼容旧版 Windows 脚本引擎。
- 单文件：`API查询.vbs` 把自己内嵌的 HTML 解到临时目录再打开，所以只有一个文件就能跑。
